# Reference selection, scale and registration

Load for a new reference set, video evidence, imported-model fitting or uncertain dimensions.

Create a small evidence ledger: source filename/ID, timestamp or crop, orientation/lens facts, feature supported and confidence. A contact sheet is an index. Open the selected full frame before claiming a hidden joint, bracket, pipe route or ground contact is visible. If no supported decoder/metadata route exists, request one; do not improvise a Blender script.

Apply still/video orientation before interpreting crops. Separate lens identity, focal length, 35 mm equivalent, digital crop and camera pose. Movie-level metadata can omit lens fields present in video-track metadata. Missing zoom information is not evidence of fixed zoom. A security-camera fisheye can establish arrangement without providing ordinary perspective measurements.

Use complementary evidence:

| Source | Usually establishes | Does not establish alone |
|---|---|---|
| User dimension | A physical scale constraint | Every surrounding dimension |
| Product front/back photos | Construction and silhouette | Actual installed bracket angle/location |
| Site photos/video | Placement, connections, relative scale | Hidden geometry or survey accuracy |
| Existing model | Reusable geometry and candidate layout | Current as-built accuracy |
| Export comparison | Numerical preservation | Real-world dimensional accuracy |

Fit a known dimension on the intended subtree. Whole imported bounds may include detached objects or house geometry unrelated to the patio. Inspect the measured selection and axes before applying scale. Count grids and repeated elements in a top/face-on view; perspective impressions are especially unreliable for rows, trim widths and table orientation.

Use metres internally unless the verb says otherwise; preserve original measurement units in the evidence. State whether a number is user-supplied, measured in the model or inferred. Reversible photo estimates can proceed within the brief; request an essential missing scale constraint rather than presenting invented precision.

Evaluate the complete parent chain when measuring alignment. Blender's usual Z-up export convention does not remove an extra rotated root. Geographic north/Sun bearing is a separate reference; do not infer it from local axes, or silently equate magnetic and true bearings.

Seek a view that resolves the disputed feature: use overhead views to count grids and side/rear views to establish supports and contact. Do not infer hidden details from a single perspective.
